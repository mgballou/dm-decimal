# dm-decimal v0.1.0

First public release of `mgballou/dm-decimal`.

- Layered `Decimal` values and arithmetic ported from break_eternity.js.
- Decimal string output follows break_eternity.js 2.1.3 and its JavaScript
  number formatting.
- Optional `DecimalCast` stores and restores values on Eloquent models.
- Requires PHP 8.3 or later; Eloquent casting requires `illuminate/database`.
